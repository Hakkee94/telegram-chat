# Telegram Chat — React и GREEN-API

Небольшой веб-клиент для переписки в Telegram. Проект сделан в рамках тестового задания: пользователь подключает свой инстанс GREEN-API, создаёт чат по номеру телефона и может отправлять и получать текстовые сообщения.

Интерфейс сделан в стиле Telegram: слева находится список чатов, справа — текущая переписка. На телефоне список и переписка переключаются между экранами.

## Возможности

- подключение Telegram-инстанса через GREEN-API;
- создание чата по номеру телефона;
- отправка и получение текстовых сообщений;
- статусы сообщения: отправляется, принято, доставлено, прочитано и ошибка;
- AI-резюме переписки: краткая сводка последних сообщений через настраиваемую модель;
- поиск по списку чатов;
- адаптивный интерфейс для компьютера и телефона;
- понятные сообщения об ошибках подключения и доставки.

Вложения, звонки и групповые чаты в проект не входят — по заданию поддерживаются только текстовые сообщения.

## Технологии

- React 19;
- Next.js 16;
- TypeScript;
- Tailwind CSS;
- GREEN-API;
- Lucide Icons.

Next.js используется как React-фреймворк: он отвечает за запуск приложения, сборку и серверный маршрут-прокси для GREEN-API.

## Локальный запуск

Для запуска понадобятся Node.js 22.13 или новее и pnpm.

Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/Hakkee94/telegram-chat.git
cd telegram-chat
```

Установите pnpm через Corepack и зависимости проекта:

```bash
corepack enable
pnpm install --frozen-lockfile
```

Запустите dev-сервер:

```bash
pnpm dev
```

После запуска откройте в браузере:

```text
http://localhost:5173
```

Если команда `corepack enable` недоступна, pnpm можно установить отдельно:

```bash
npm install -g pnpm
pnpm install
pnpm dev
```

## Подключение GREEN-API

1. Создайте Telegram-инстанс в [личном кабинете GREEN-API](https://console.green-api.com/).
2. Авторизуйте аккаунт Telegram и дождитесь состояния `authorized`.
3. В настройках инстанса включите получение входящих уведомлений (`incomingWebhook: yes`).
4. Оставьте поле `Webhook URL` пустым — приложение получает уведомления через HTTP API.
5. Откройте меню приложения и выберите «Подключить GREEN-API».
6. Введите `apiUrl`, `idInstance` и `apiTokenInstance` из карточки инстанса.
7. Нажмите «Новый чат» и укажите номер получателя в международном формате, например `+7 999 123-45-67`.

После создания чата можно отправлять сообщения клавишей Enter. Чтобы добавить перенос строки, используйте Shift+Enter.

Для проверки двусторонней переписки ответьте на сообщение с аккаунта получателя в Telegram. Ответ появится в открытом чате автоматически.

Токен, чаты и сообщения хранятся только в памяти текущей вкладки. После обновления страницы подключение и список чатов нужно создать заново.

## Как устроен проект

- `app/page.tsx` — главная страница и связка интерфейса с логикой приложения.
- `components/chat/chat-workspace.tsx` — список чатов, окно переписки, поле ввода и сообщения.
- `components/chat/connection-dialog.tsx` — форма подключения GREEN-API.
- `hooks/use-telegram.ts` — состояние приложения, создание чатов, отправка сообщений и получение уведомлений.
- `lib/chat/api.ts` — типизированные запросы к внутреннему API-маршруту.
- `lib/chat/model.ts` — обработка телефонов, сообщений, дублей и статусов доставки.
- `lib/chat/config.ts` — общие ограничения, например максимальная длина сообщения.
- `app/api/green/route.ts` — серверный прокси к GREEN-API с проверкой адреса и параметров запроса.
- `components/chat/ai-summary.tsx` — кнопка и панель AI-резюме в шапке переписки.
- `lib/chat/ai.ts` — отбор сообщений, подготовка промпта и вызов `/api/ai`.
- `app/api/ai/route.ts` — серверный вызов OpenAI-совместимого API модели; ключ хранится на сервере.
- `tests/chat.test.mjs` — тесты основных функций и API-контрактов.
- `tests/chat-ai.test.mjs` — тесты модуля AI-резюме.

Браузер обращается к `/api/green`, а этот маршрут уже отправляет запрос в GREEN-API. Благодаря этому данные не зависят от CORS-ограничений браузера.

## Настройка AI-резюме

Функция опциональна: без переменных окружения приложение работает как раньше, а кнопка покажет понятное сообщение о том, что AI не настроен.

Переменные окружения:

```text
AI_API_KEY   — ключ API модели (обязательно);
AI_MODEL     — имя модели, например glm-5.4 (обязательно);
AI_API_BASE  — базовый адрес OpenAI-совместимого API,
               по умолчанию https://api.z.ai/api/paas/v4.
```

Примеры провайдеров: Z.ai, OpenRouter или локальный Ollama (`http://127.0.0.1:11434/v1`). Переписка передаётся в модель только при нажатии кнопки «Резюме»; ключ остаётся на сервере.
